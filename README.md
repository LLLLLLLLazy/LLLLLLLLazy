## About me

I am an undergraduate student at **Northwestern Polytechnical University**. My current academic focus is **quantum computing**, particularly quantum error correction. I am also interested in computer systems, the practical use of new AI models, emerging consumer hardware, game engines, and game development.

I enjoy working across abstraction layers—from quantum decoding algorithms and experimental evaluation to processor microarchitecture, RTL implementation, and FPGA validation.

> **Currently:** studying quantum error correction and exploring low-latency, parallel decoding methods for quantum LDPC codes.

## Featured work

### [Low-Latency Parallel-Window Decoding for Quantum qLDPC Codes](https://llllllllazy.github.io/#research-experience)
`Quantum Computing` `Decoding Algorithms` `Experimental Evaluation`

Studying real-time decoding under circuit-level noise and developing candidate-selection methods that reduce boundary-error propagation while preserving small-window parallelism.

### [LoongArch32 Dual-Issue Pipelined Processor](https://gitee.com/yan098/cpu-grass.git)
`Computer Architecture` `Verilog` `FPGA`

Led the design of an in-order, dual-issue, eight-stage processor for the reduced 32-bit LoongArch instruction set. The implementation reached **90 MHz** on FPGA, passed all official tests with a score of **2.142**, and booted Linux through U-Boot network loading.

### RAG-Based Educational Data Mining System
`RAG` `Semantic Retrieval` `Knowledge Systems`

Developed the core retrieval-augmented generation pipeline for a campus-specific question-answering platform, using contextual semantic retrieval and local knowledge to reduce domain-specific hallucinations.
